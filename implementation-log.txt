## done
- mixHue follows the direction the user asked for (signed delta c1.h -> c2.h),
  not the long or short arc — swapping c1/c2 reverses the trace. t already
  oscillates 0->1->0 via sin in pencilColor, so the trace cycles c1 -> c2 -> c1
  along that exact direction.
- whole mode now shares the same math: added oscT(progress, animSpeed) helper
  (= 0.5-0.5*cos(2*pi*f), identical sine bump to pencilColor's 0.5+0.5*sin) and
  use it in computeWhole + recolorWhole in place of the linear ramp. animSpeed
  still scales how many forward+back cycles fit in one closed period; seam now
  closes (t=0 at both ends), so the ring flows color1 -> color2 -> color1
  along the same single arc as animate mode.
- added per-pencil animMode ('frequency' | 'cycles', default 'frequency') toggle:
  - 'cycles': 0->1->0 cosine bump (color1-color2 and back), 1 bump per 1/animSpeed
    seconds in animate mode; cycles-per-period in whole mode (via oscT).
  - 'frequency': sawtooth frac(time*animSpeed) - hue advances linearly then wraps
    (hue-per-tick ramp); no continuous muddy sine.
  Slider max raised 0->2 to 0->4 (up to 4 hue cycles). Whole mode always uses
  the cycles arc math (its natural meaning) regardless of animMode.
- GUI: mode is now a pair of .btn toggle buttons ('cycles' / 'frequency',
  .active on selected) instead of a dropdown; slider prefix relabels to
  'cycles ' / 'hue/sec '. Toggle triggers onGearParam(gear,'color').

### 3. hollow glass = the reference shader, formula for formula
- the drift, root-caused against luncat8/glass-spheres-shader (hollow_bubbles.js):
  a) the reflections sampled a custom view-space studio sky (envView + a
     warm key light) instead of the reference checker-land env with its sun;
  b) the tonemap dropped the reference gamma (pow 1/2.2 after the filmic
     curve) - rims rendered flatter and darker;
  c) the Beer-Lambert absorption divided the glass path by uWall*R (x0.16),
     so the SAME tint slider read ~2.5x weaker at the default wall and 10x
     stronger / weaker at the extremes - absorption in the reference depends
     only on the path actually travelled (chord * 3.5);
  d) the absorption palette mixed the user tint colour at 30% instead of the
     reference golden-ratio tintOf.
- render.js: GLSL_ENV is now ONE shared GLSL constant - the reference
  GLSL.env themes 0-2 + envSun (SUN_DIR mirrored to (0.35, 0.62, 0.70)

  spliced into BOTH the background pass (which already carried a copy of the
  same functions inline) and SPH_COMMON. the sphere env is sampled in WORLD
  space, so the shells reflect the env the canvas actually draws behind
  them, and a uTheme uniform (R.bgTheme(App.background), 'black' -> checker)
  keeps the reflections in step with the background select.
- hollow: crossWall now absorbs exp(-tintOf(idx) * uDensity * chord * 3.5)
  with the reference tintOf - per-gear golden-ratio tints, no user tint; the
  tonemap gets the reference gamma; envView / absorbOf are deleted. every
  other number (film, swirl, Fresnel, F2, bend, dispersion, wall events)

  sliders and nothing else).
